# Earnings variance v2 — pre-experiment rolling-admission redesign

Status: pre-experiment protocol with a separate offline v2 admission/receipt/evaluation harness. Not an active registration; v1 remains unchanged. No valid holdout predictions or outcomes have been collected. This supersedes the proposed requirement to know every future earnings date before November 2; it does not overwrite the original v1 registration receipt. A reviewed implementation, complete source map, model procedure and fresh exclusive registration must be frozen before holdout. Never feed rolling events into the existing static-manifest harness by editing its manifest.

Unchanged: the 25 issuers in earnings_variance.POLICY; November 2 2026 through March 31 2027 prediction cutoffs; five subsequent exchange sessions; baseline prior-20-session mean squared log return plus opening-gap squared/5; candidate baseline*(1+0.5*uncertainty_score); at least 30 eligible events and five issuers; >=5% QLIKE loss reduction and positive issuer-average improvement for >=70% of issuers; complete eligible population; final-only acceptance; zero incremental inference budget and no trading authority. Preserve original receipts and code/policy hashes. Calendar or rule changes require a new version before any holdout use, not a retrospective edit.

Before holdout, bind a source map for every fixed issuer: CIK, exact official SEC submissions endpoint, exact issuer investor-relations release index/domain, and source-map hash. Freeze the complete exchange calendar through the final possible fifth session, including venues, holidays, early closes and timezone version. Freeze parsers/extraction code, the exact model revision and its identity reference, all effective settings, the fixed prompt and output schema. There are no credentials or model calls in this proposal.

Deterministic discovery and admission:

1. Poll all 25 fixed official source pairs at every UTC hour, seven days a week, from registration through April 1 2027. Each slot gets one immutable receipt containing scheduled/observed times, every issuer/source status, content hash, and all candidate accession/release identifiers. One fetch per source per slot; no hidden retries. Record failures and missing slots. Store raw source bytes and parsed records. Missing required discovery coverage blocks final acceptance unless a complete authoritative retrospective source census proves no eligible event was missed; such a reconciliation must be retained and cannot invent prospective admission timestamps.
2. A candidate is an original SEC 8-K Item 2.02 quarterly/annual earnings announcement with its original issuer earnings-release exhibit and independently verifiable official release timestamp. The issuer must be in the frozen map. Freeze accession, issuer, fiscal period, source URLs/hashes, SEC acceptance time, original release time, first-seen time, and every discovery receipt linking to it. Do not select reports based on language, score, price moves or model success.
3. Define the event's opening session as the first regular equity opening strictly after the official release timestamp. Its cutoff is that same session's official closing auction. This definition handles before-open, after-close, weekend and intraday announcements without using an already-observed post-cutoff return. The existing baseline opening gap is measured for that frozen opening session. Freeze the prior 20 return/session dates and the five subsequent outcome sessions from the registered calendar.
4. Admission must be durably timestamped by five minutes before that opening session. An event first discovered after that deadline is SKIPPED_LATE_DISCOVERY and remains in the census. Cutoff outside the fixed holdout is SKIPPED_OUTSIDE_WINDOW. Non-earnings, unsupported form, missing/unverifiable release time, source identity failure, or non-unique fiscal-period identity have their own fixed skip codes. Missing source coverage is a coverage failure, not evidence of no events.
5. Use issuer CIK plus fiscal-period end as the economic event ID; preserve accession and release identifiers as provenance. The earliest original qualifying official release is canonical. Exact repeats append DUPLICATE with a pointer and never create another sample. A later 8-K/A or changed source hash appends AMENDMENT, with both original and new hashes. Never replace admitted text or model output. A material correction discovered before the prediction deadline invalidates the event under a fixed objective correction rule (changed reported financial figures or official withdrawal), with evidence retained. Post-cutoff corrections are flagged and retained in the primary population; any sensitivity analysis must be separately labelled and cannot determine acceptance. An unresolvable conflicting original identity is recorded as a protocol failure, not silently selected.
6. Admission is final before inference or feature inspection beyond objective eligibility fields. After admission, model failure, missing prices/quotes, missing score, unavailable budget or missed sealing deadline is ADMITTED_INCOMPLETE, not a discretionary exclusion. One model attempt per admitted event, no retries or best-output selection. Seal source text, exact model request/response receipt, quote, score, features, costs and timestamps before cutoff; an incomplete admitted event blocks acceptance. All six outcome prices are timestamped at cutoff and the following five closes.
7. Maintain an append-only hash-linked census of every discovered candidate, admission, duplicate, amendment, skip and failed attempt, together with the complete hourly source-health ledger. Final evaluation reconciles the authoritative source census to this ledger and requires exactly one prediction and outcome for every valid admitted event. Retain all skipped and incomplete rows in the published denominator/audit report; never drop events after seeing outcomes. Required acceptance sample is still >=30 events and >=5 issuers; insufficient count is inconclusive, not grounds to extend, shorten or relax the protocol after results.

Before implementation, the objective material-correction parser, source map and timestamp-verification rules must be made machine-checkable and covered by fixtures for late discovery, SEC filing lag, holidays, duplicate releases, amendments, feed outages, missing model output and conflicting fiscal periods. This is an explicit readiness blocker, not a completed collection system.

Earliest possible cutoff remains November 2, with its fifth-session outcome November 9; final evaluation remains no earlier than April 1 and may wait through April 7 at 20:00 UTC for a March 31 cutoff. Preliminary records may establish operational completeness but cannot trigger early acceptance. The frozen model/recipe and a genuinely no-incremental-cost inference source remain unresolved. Choosing a paid provider requires separate budget authorization; historical classifications cannot substitute.


Implementation boundary (2026-10-20): research/earnings_variance_v2.py implements exclusive registration, hourly scan receipts, complete issuer-check coverage, deterministic admission/skips, duplicate/amendment handling, append-only hashed journal, one prediction attempt, signed exact original request/response binding, and complete-population final evaluation. It has no network collector, inference client, trading or deployment entrypoint. Raw public-source collection, source authentication and semantic extraction remain an external reviewed input boundary. The supplied production configuration is entirely unconfigured and register() rejects it. Source maps, model revision/settings and a verified trusted capture recorder public key must be supplied before a valid registration exists.

Receipt format: an Ed25519 signature from that preregistered recorder covers original request_raw and response_raw strings, source_text, event_id, features, requested_at and received_at. The model request must exactly match the frozen Responses API request (model, settings and fixed prompt plus full source text). Scores and quotes are parsed only from the original completed response. Evaluation re-verifies signatures and recomputes predictions. This authenticates the chosen recorder's capture, not the provider independently; no recorder identity is presently verified. Tests use ephemeral keys and explicit engineering_smoke evidence, never predictive evidence.

Current coverage rule is deliberately strict: any missing/failed hourly issuer-source check blocks acceptance. Retrospective reconciliation is not implemented and cannot waive that block. Unknown amendments block acceptance. Post-cutoff amendments remain in the primary population. Admission/skip records retain all normalized candidate evidence and hashes; raw source material must be retained by the reviewed collector and its hashes supplied. Files are a local audit trail, not a substitute for independently timestamped storage or authenticated source provenance. Calendar reference was collected for free; listing-venue reconciliation remains pending. Do not register its limitations as verified without that review.

Timestamp clarification: first_seen_at is immutable for (economic event ID, accession, source content hash). Repeated scans retain that timestamp; an amended source version has its own first-seen time. observed_at is recorded by the harness for each current scan and is separate from original discovery. Admission still uses the current observation time, so an old first-seen value cannot bypass the admission deadline. Conflicting first-seen values for the same source version fail closed, including duplicates within one scan.
