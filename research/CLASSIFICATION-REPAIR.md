# Investor classification repair (review only)

This change addresses the October20 classification failures without altering model selection, the daily20-attempt budget, source freshness rules, paper execution authority or risk settings. It is not deployed. The v4 boundary preserves v1-v3 policies, historical classifications, rejected-attempt diagnostics and existing forecast lineage. The client code is included in the frozen dependency hash.

Evidence and limits: runs50411,50455,50503 and50550 rejected schema/quote output; run50510 timed out fetching SEC Form4/13D feeds and recovered in50514. The original implementation stored only error categories, not rejected response bodies (call_json used store=False and no capture). Exact malformed fields or model-generated quotes cannot be recovered from available evidence. Retained source lengths for the three repeatedly failing filings are1485,1608 and2711 characters; source hashes and original text remain intact, including a literal question mark in place of punctuation in one filing. No punctuation repair or guessed quote is allowed. This is a repair of confirmed request-format, retention and scheduling weaknesses, not a claim of empirically corrected model accuracy.

Requests now opt into the Responses API's strict JSON schema for the existing boolean/enums/string fields. Other call_json callers retain their prior request payload. The prompt presents full source as a JSON string and explicitly requires an exact contiguous10-1200-character quote, including relevant negation. Local validate_catalyst checks remain mandatory and unchanged. Structured formatting does not prove semantic support or guarantee a valid quote. API reference: https://developers.openai.com/api/docs/guides/structured-outputs .

A single transaction reserves the daily budget and immutable request intent before transport. The original HTTP response body, status and exact request payload are saved before JSON/status/refusal/content validation. Evidence resides only in the restricted research directory/database (0700/0600); reports and model_error records retain bounded diagnostics and never echo raw payloads or credentials. Headers/authentication are not stored. A capture/storage failure prevents acceptance; orphan intents still count against the per-event cap. These local receipts are not independent provider attestation or a reconciled bill.

Queue: prioritize unattempted eligible filings, then least-recently-attempted filings, preserving existing prospective-before-historical priority and the one-hour cooldown. Each event has a lifetime maximum of3 attempts, including old model_error receipts and unfinished new intents. Neither UTC midnight nor upgrade resets that counter. More-than-three-attempt legacy failures remain explicitly pending/attempt_limit_blocked, requiring reviewed reprocessing rather than automatic retries. The global20/day limit is unchanged. No fresh paid calls were made to test the change.

Returned invalid content (including malformed JSON, refused/incomplete responses and invalid quotes/schema) remains DEGRADED/unclassified but does not immediately retry the whole collector. Request timeouts/network failures and HTTP408/429/5xx remain retryable. No-op statuses distinguish CLASSIFIED, NO_ELIGIBLE_WORK, UNRESOLVED_DEFERRED and DAILY_BUDGET_REACHED. Coverage reports budget, cooldown and attempt-limit blockage separately; no unresolved item is marked successful.

ARKW remains excluded while stale, with its existing persisted1/2/4/6-hour backoff and calendar checks. Existing SEC source failures remain retryable and distinct from a completed degraded observation cycle; no timeout increase or unsafe fallback is introduced. Offline regressions cover stale-source exclusion/backoff, SEC timeout reporting, exact corrupted-source punctuation, original response preservation including refusal/parser failures, queue fairness, old/crash attempt limits, midnight/cooldown, budget exhaustion, transport vs content errors and v4 lineage. Synthetic responses are engineering fixtures only. Runtime and PR16 are unchanged.
